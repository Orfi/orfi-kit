# orfi-kit-run-codegraph-phase

> Run codegraph for a specific GSD phase.

## What it does

Runs codegraph for a single GSD phase. You pass the phase number as an argument, and the command runs codegraph scoped to that phase.

## How to invoke

```
/orfi-kit-run-codegraph-phase <PHASE_NUMBER>
```

The argument you supply becomes `PHASE_NUMBER` — the GSD phase that codegraph is run for.

## Behavior / rules

- Takes a single argument, `PHASE_NUMBER`.
- Runs codegraph for the GSD phase identified by that number.

## Notes

- Part of the orfi-kit GSD command set.
